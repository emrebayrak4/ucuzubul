# @pricora/mobile — WhichLess app

**Rebrand (WhichLess):** app name comes from `brand.name`; slug `whichless`; schemes `whichless://` (primary) and `pricora://` (legacy, temporary); **bundle ids changed to `com.afterwish.whichless`** (iOS + Android) — a new store identity, so EAS credentials and any store listings must be created for the new id. Icons, adaptive icon, splash and in-app logo use `assets/brand/*` (copied from `packages/config/assets`).

Expo SDK 58 · Expo Router (typed routes, `src/app`) · TypeScript strict · TanStack Query (persisted) · Reanimated 4 · native bottom tabs.

## Run
```sh
pnpm -C apps/mobile dev            # Metro; press a / i, or scan with a dev build
pnpm -C apps/mobile typecheck
pnpm -C apps/mobile lint
pnpm -C apps/mobile export:android # = npx expo export --platform android
pnpm -C apps/mobile export:ios
pnpm -C apps/mobile doctor         # expo-doctor
```
Use `pnpm -C`, not `pnpm --filter` (Windows long-path issue, see docs/TASKS.md).
Typed routes (`.expo/types/router.d.ts`) are generated by `expo start`; typecheck passes without them, with looser `Href` types.

## API URL
`EXPO_PUBLIC_API_URL` (origin, no `/v1`). If empty:
- Android emulator → `http://10.0.2.2:4400`
- iOS simulator → `http://localhost:4400`
- physical device in dev → `http://<Metro host LAN IP>:4400` (from Expo `hostUri`)

See `.env.example`. Release builds must set `EXPO_PUBLIC_API_URL` (https).

## Decisions
- **Styling: StyleSheet + `@pricora/design-tokens`, not NativeWind.** NativeWind 4 needs Tailwind v3, and the monorepo
  hoists Tailwind 4.3 for web/admin. Two Tailwind majors in a hoisted layout is fragile, and the tokens TS object
  already covers RN (colors per scheme, type steps, spacing, radius, native shadows). See `src/lib/theme.tsx` and `src/components/ui.tsx`.
- **React 19.3.1** (same as web), not Expo's listed 19.3.0, so the hoisted monorepo has exactly one React. Excluded via
  `expo.install.exclude`; RN 0.88's renderer has no strict patch-version check. **TypeScript 5.9.3** is the repo pin (Expo suggests 6.x).
- **Charts:** hand-drawn with `react-native-svg` (no chart lib). Real points only, and the line breaks across gaps over 3 days.
- **Bottom sheet:** RN `Modal`, so no extra native dependency.
- **Auth:** the `pc_session` httpOnly cookie works through the native cookie store, which acts as the fallback. Native mode: every request sends
  `x-pricora-client: native`; login/register return `sessionToken` (A04, verified live), which is stored in SecureStore and sent as `Authorization: Bearer`. Bearer requests need no CSRF; the cookie fallback still sends `x-csrf-token` from login/me. Optional biometric lock (expo-local-authentication).
- **Offline:** the TanStack Query cache is persisted to AsyncStorage (home, product, history and hotel queries only, never account data),
  `networkMode: offlineFirst`, NetInfo drives `onlineManager`, and the offline banner shows on every screen. Recently viewed is stored on the device.
- **Outbound:** "Visit store" opens `/v1/go/:offerId` (or `/v1/travel/go/...`) in the in-app browser, never a raw retailer URL.
- **Demo data:** every offer, fare or rate with `source: "demo"` shows a `DemoBadge`, and screens show a demo notice when the aggregate is demo.

## Deep links
Schemes `whichless://` (e.g. `whichless://products/<slug>`) and legacy `pricora://`. App routes mirror web paths (`/products/[slug]`, `/flights`,
`/hotels/[id]`, `/login`…), so universal links map 1:1. `associatedDomains` and Android `intentFilters` for `whichless.com` (from `brand.domain`) are
placeholders. They need `/.well-known/apple-app-site-association` and `assetlinks.json` on the web domain.

## Needs a device / EAS to verify
Camera scanning, push token (needs `EXPO_PUBLIC_EAS_PROJECT_ID` + physical device), biometrics, SecureStore, native tabs
appearance, haptics, cookie persistence across restarts, universal links.
